# Image Sources for Space Invaders Political Edition

This game uses images of political figures. You can download them automatically or manually.

## Automatic Download (Recommended)

Run the download script:

```bash
python download_images.py
```

This will download all required images from Wikimedia Commons to the `images/` directory.

## Manual Download

If the automatic download fails, you can manually download images from these sources:

### Player Character

**Zohran Mamdani** (NYC Mayor, 2026)
- Wikimedia Commons: https://commons.wikimedia.org/wiki/Category:Zohran_Mamdani
- Official NYC Mayor's Office: https://www.nyc.gov/mayors-office
- Save as: `images/zohran_mamdani.jpg`

### Enemy Characters

**Andrew Cuomo** (Former NY Governor)
- Wikimedia Commons: https://commons.wikimedia.org/wiki/Category:Andrew_Cuomo
- Search: "Andrew Cuomo official photo"
- Save as: `images/andrew_cuomo.jpg`

**Donald Trump** (47th President)
- Official portrait (Library of Congress): https://www.loc.gov/item/2017656484/
- Wikimedia Commons: https://commons.wikimedia.org/wiki/Category:Official_portraits_of_Donald_Trump
- Save as: `images/donald_trump.jpg`

**JD Vance** (Vice President)
- Official portrait (Wikimedia): https://commons.wikimedia.org/wiki/Category:Official_portraits_of_JD_Vance_as_vice_president
- Library of Congress: https://www.loc.gov/item/2025163295/
- Save as: `images/jd_vance.jpg`

## Image Requirements

- Format: JPG (PNG also supported)
- Recommended size: 400x400 to 1000x1000 pixels
- The game will automatically scale images to fit

## Playing Without Images

If you don't have the images, the game will still work! It will use colored geometric shapes as fallback graphics:
- Player: Green triangle (spaceship)
- Enemies: Red/yellow rectangles (invaders)
